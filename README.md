# RoughScore

노래를 들으면서 필요한 부분만 남기는 macOS 기타 TAB 스케치 앱 초안입니다.
자동으로 완성된 악보를 만드는 것보다, **불확실한 부분을 비워 두고 직접 고치는 흐름**을 우선합니다.

## 실행

Xcode 27 SDK / Swift 6.4로 빌드를 확인합니다. 최소 실행 OS는 macOS 15이며, Music Understanding 분석은 macOS 27 이상에서만 활성화됩니다. 외부 패키지 의존성은 없습니다.

```sh
zsh scripts/build-app.sh
open build/RoughScore.app
```

Xcode에서 `Package.swift`를 열고 RoughScore 실행 타깃을 실행할 수도 있습니다.
오래된 SDK에서는 `canImport(MusicUnderstanding)` 분기가 분석을 제외합니다. 해당 SDK 조합의 빌드는 별도 검증하지 않았습니다.

## 현재 사용 흐름

### 악보처럼 보는 긴 곡

기본 화면은 `악보 보기`입니다. 한 줄에 4개 또는 8개의 마디를 배치하고 여러 줄을 페이지로 묶습니다.
박자 분석 전에는 2초 시간 블록을 기준으로 한 줄 8초 또는 16초로 나누며, 마디나 박자를 추정해 표시하지 않습니다.
원곡의 분석 마디를 우선 사용하고, 원곡 분석이 없으면 사용 가능한 채널 분석을 사용합니다.

- 상단 `곡 전체` 지도에서 3분 전체의 L/R 메모 위치와 현재 페이지 범위를 함께 봅니다. 원하는 위치를 클릭하면 해당 악보 페이지로 이동합니다.
- 페이지 선택과 앞/뒤 버튼으로 이동합니다. `재생 따라가기`를 켜면 재생 위치에 맞춰 페이지가 넘어갑니다. 직접 페이지를 넘기면 따라가기가 꺼져서 읽던 페이지를 유지합니다.
- 기본 화면은 클릭·입력하기 쉬운 크기로 악보를 표시합니다. `페이지 맞춤`을 켜면 창 높이에 맞춰 한 페이지의 모든 줄을 함께 볼 수 있습니다.
- 기본 `파형`은 각 TAB 바로 위에 해당 L/R 채널의 파형을 표시합니다. 파형과 음은 동일한 마디·시간 좌표를 사용합니다. 파형을 클릭하면 그 시간으로 이동하고, 아래 TAB 줄을 클릭하면 같은 시점에 `?` 메모를 추가합니다. `L/R 함께`에서는 채널마다 파형이 따로 보입니다.
- `L/R 함께`는 두 기타를 같은 시간의 위아래 TAB으로 묶어 표시합니다. 페이지당 기본 4줄, 두 파트를 함께 볼 때는 2쌍입니다.
- TAB 클릭 후 숫자를 치면 그 자리의 프렛을 바로 입력합니다. `1` 다음에 `2`를 0.9초 이내에 치면 `12`가 됩니다. 기존 음도 클릭하고 새 숫자를 치면 바뀝니다. 상세 패널은 `상세` 버튼 또는 `I`로 직접 열며, 선택만으로 악보 폭이 바뀌지 않습니다.
- 파형을 클릭한 뒤 숫자를 쳐도 현재 편집 줄에 바로 기록됩니다. `↑↓`로 편집 줄을 바꿀 수 있으며, 악보의 원형 커서가 입력할 위치를 표시합니다.
- 각 줄의 `구간 편집`을 누르면 그 줄의 시간 범위에 맞춰 파형·확대 TAB 편집으로 전환합니다. 상단에서 언제든 악보 보기로 돌아갑니다.
- `데모 → 긴 곡 데모 · 3분`으로 긴 곡의 페이지 배치를 시험할 수 있습니다. 이 데모도 합성 오디오와 수동 메모이며 분석 결과를 만들어 넣지 않습니다.

가변 템포에서도 검출 마디 경계를 사용합니다. 줄바꿈·페이지 전환·표시 밀도 변경은 원래 메모의 초 단위 시간과 음표 길이를 바꾸지 않습니다.

1. 원곡, 기타 녹음 또는 다른 도구로 이미 분리한 기타 스템을 엽니다.
2. 항상 보이는 재생 도구줄에서 Stereo / L / R을 선택합니다. 모노 파일이면 양쪽이 동일하다고 표시합니다.
3. 파형 클릭으로 위치를 찾고, 드래그로 A–B 반복 구간을 잡습니다. 기본 반복은 꺼져 있으며 다른 위치를 클릭하면 이전 반복에서 빠져나옵니다. `[` / `]`로도 범위를 정할 수 있습니다.
4. 필요하면 0.5× / 0.75× 감속 재생을 사용합니다. `AVAudioPlayer.rate`로 피치를 유지합니다. ([Apple 문서](https://developer.apple.com/documentation/avfaudio/avaudioplayer/rate))
5. TAB의 줄을 클릭하고 숫자를 입력합니다. 음을 모르면 `?`로 남깁니다. `↑↓`로 줄 이동, `←→`로 시간 ±50ms, `Shift+←→`로 ±10ms 조정, `Tab` / `Shift+Tab`으로 다음 / 이전 음을 선택합니다. `Delete`로 삭제하며 `⌘Z` / `Shift+⌘Z`로 되돌립니다.
6. `음표 길이`를 켜면 선택한 메모에 길이를 지정할 수 있습니다. 미지정으로 두어도 됩니다.
7. 원곡, L, R에 대해 `현재 소스 분석`을 각각 실행하면 박 / BPM / 시작 조성 / 구조 결과가 별도로 보관됩니다. 박 스냅은 분석된 박에서 120ms 이내의 새 메모만 이동시킵니다.
8. `.roughscore` 링크 프로젝트 또는 `.roughscorepkg` 오디오 포함 프로젝트로 저장합니다. `내보내기`에서 6줄 TAB·손실 없는 이벤트 표·PDF·인쇄를 선택하고, 전체/선택/직접 지정 시간 구간과 Guitar L/R을 정합니다. PDF·인쇄는 A4/Letter·여백·기록된 음표 길이·준비된 파형 개요와 문서 미리보기를 제공합니다.

저장한 프로젝트가 있으면 앱을 다시 켤 때 이어서 엽니다. 처음 실행하면 합성 스테레오 오디오와 수동 TAB 예시가 열립니다. **데모 메모는 자동 채보 결과가 아닙니다.**
한 시점에 여러 줄에 메모를 놓아 코드를 간단히 기록할 수 있습니다. 빈 구간은 미채보 상태이며 쉼표가 아닙니다.

## Music Understanding의 역할과 한계

[Apple 공식 문서](https://developer.apple.com/documentation/MusicUnderstanding)와
[WWDC26 소개](https://developer.apple.com/videos/play/wwdc2026/253/)를 기반으로 실제 `MusicUnderstandingSession`을 연결했습니다.
설치된 Xcode 27 SDK의 Swift 인터페이스에서 API 시그니처와 OS 가용성을 확인했습니다.

| 처리 | 현재 초안 | 다음 단계 |
| --- | --- | --- |
| 박, 마디, BPM, 조성, 구조 | Music Understanding의 실제 분석, 검출 마디 기반 악보 페이지, 구조 구간 표시 | 조성 변화 표시 |
| 악기 활동 | vocal / drum / bass / other 중 other의 구간을 프로젝트에 저장 | 보조 표시로만 사용 |
| 기타 소리 분리 | 미구현. 이미 분리한 파일을 열 수 있음 | 별도 기타 스템 모델 + Core ML 어댑터 |
| L/R | PCM을 각각 모노 파일로 추출, 별도 재생·분석·TAB | 스테레오 보존 분리 모델의 결과에서도 같은 흐름 |
| 각 음 위치·음고 검출 | 미구현. 사용자가 시간축에 입력 | 별도 onset / 다성 음고 추정 모델 |
| TAB 운지 | 사용자가 줄·프렛 선택 | 튜닝·포지션·이동량 기반 후보 제안 |
| 음표 | 선택형 길이 기호 | 필요할 경우 리듬 줄기와 정식 오선보 |

Music Understanding은 기타 스템, 개별 음의 음고·시작·끝, 줄·프렛을 제공하는 API가 아닙니다.
SDK의 `other`는 기타 전용 분류가 아니므로 기타 검출로 표시하지 않습니다.
L/R 또한 서로 다른 기타를 보장하지 않습니다. 양쪽에 같은 기타, 잔향 또는 다른 악기가 들어 있을 수 있습니다.

## 후속 채보 엔진 설계

```text
스테레오 원곡
  ├─ Music Understanding → 박 / 조성 / 곡 구조
  └─ 기타 전용 분리 모델 → 스테레오 기타 스템
       ├─ 원본 시간·샘플레이트 정렬 유지
       ├─ L onset / 다성 음고 추정 → 시간 + 음고 + 신뢰도
       └─ R onset / 다성 음고 추정 → 시간 + 음고 + 신뢰도
            → 운지 후보 → 사용자 선택 → 부분 TAB
```

분리 모델은 가능하면 스테레오 입력 전체를 처리해 공간 정보를 보존하고, 출력 스템의 L/R을 나누어 채보합니다.
독립 모노 분리는 원곡 / 스테레오 분리 결과와 비교 가능한 대안으로 두되, 좌우 파트 분리와 혼동하지 않습니다.
모델의 패딩·지연·샘플레이트 변환을 보정한 원곡 초 단위 시간으로 모든 결과를 저장합니다.

자동 후보는 `시간`, `MIDI 음고`, `신뢰도`, `음고 지속 시간`, `운지 후보`, `입력 채널`을 가져야 합니다.
확정 메모와 후보를 분리하고, 낮은 신뢰도는 `?` 또는 검토 대상으로 남깁니다.
자동 음 지속 시간과 사용자가 선택하는 음표 길이는 별개입니다.
벤딩·슬라이드·비브라토, 왜곡 기타 배음, 두 기타의 겹침은 초기 정확도 검증에서 별도 실패 유형으로 기록합니다.
기본은 사용자가 선택한 짧은 구간만 분석하고, 미채보 구간에 음이나 쉼표를 자동으로 채우지 않습니다.

`GuitarStemSeparating` 프로토콜을 분리 모델의 연결 지점으로 마련했습니다. 현재 연결된 모델은 없습니다.
다음 구현 순서는 기타 스템 품질 비교 → 깨끗한 단음 기타의 음고 후보 → 코드·왜곡 기타 → 운지 후보입니다.
분리/채보 모델은 실제 기타 스템을 출력하는지, 라이선스, 오프라인 실행, Core ML 변환, 메모리·지연을 검증한 뒤 선정합니다.

## 파일·처리 범위

- 기본 튜닝 E B G D A E, 6줄 / 0–24프렛. 다른 튜닝·카포 편집은 후속 범위입니다.
- 오디오는 AVAudioFile이 디코딩하는 모노/스테레오 형식, 최대 1시간입니다. 파형은 청크 단위로 읽습니다.
- 파형은 약 10ms 단위의 최대 진폭을 보관합니다. 표시할 가로 픽셀 구간에 포함되는 최대값을 모아 짧은 어택이 생략되지 않게 합니다. 가변 템포의 마디는 TAB과 동일한 시간 변환으로 그립니다.
- L/R 청취는 해당 채널을 모노로 양쪽 출력에 재생합니다. 감속 재생은 `AVAudioPlayer`의 피치 유지 기능을 사용합니다.
- 프로젝트는 Codable JSON입니다. 음표 길이·프렛이 nil이면 미지정 상태가 그대로 저장됩니다.
- 내보내기는 편집기와 분리된 문서 사본을 사용합니다. 원래 초 단위 시간·UUID·L/R·미지정 리듬과 제어 문자가 있는 메모는 이벤트 TSV에서 JSON 셀로 왕복 보존됩니다. TAB/PDF는 각 음에 독립된 6줄 열을 두며 빈칸을 쉼표로 추정하지 않습니다. 박 기준은 내보내기를 시작한 청취 자산의 저장된 분석입니다. 파형은 원곡 시간축의 L/R 개요로 별도 표시하며 음 간격을 박/리듬으로 추정하지 않습니다. 오프라인에서는 파형 없이 내보낼 수 있습니다.
- 링크 형식 `.roughscore`는 외부 오디오의 절대 경로를 저장합니다. 파일이 이동하면 `오디오 다시 연결`로 지정합니다. `다른 이름으로 저장 · 오디오 포함` 또는 `사본 저장 · 오디오 포함`은 원곡과 스템을 복사한 `.roughscorepkg`를 만들며, 패키지 안의 상대 경로로 연결하므로 폴더를 옮겨도 함께 재생할 수 있습니다. 사용자 원본은 그대로 유지됩니다.
- `다른 이름으로 저장`은 성공 후 새 파일을 활성 저장·autosave 목적지로 사용합니다. `사본 저장`은 현재 목적지·dirty 상태·실행 취소 기록을 유지합니다. 새 목적지의 기존 파일은 덮어쓰지 않으며, 활성 패키지 내부에는 새 프로젝트를 저장할 수 없습니다. 실패나 대화상자 취소는 기존 작업을 유지합니다. `프로젝트 열기`에서 두 형식을 선택할 수 있습니다.
- 임시 데모 오디오는 첫 저장 시 프로젝트 옆에 WAV로 복사합니다. 프로젝트를 옮길 때 이 파일도 함께 옮겨야 합니다.
- 원곡 재연결 시 메모가 오디오 길이 밖으로 나가면 연결을 거절합니다. 길이가 바뀌면 이전 분석을 비웁니다. 내용이 다른 동길이 파일까지 자동 식별하지는 않습니다.
- 프로젝트 저장은 원자적으로 게시합니다. 기존 링크 JSON·패키지 metadata·전체 패키지를 교환한 뒤 실제 밀려난 문서, 요청한 저장 위치와 포함 자원이 검증한 상태인지 확인합니다. 다른 작업의 파일이 끼어들면 복원하고 저장을 거절하며, 복구 중 추가 버전은 삭제하지 않고 오류에 표시한 위치에 보관합니다. 폴더가 이동한 경우 복구 파일의 현재 경로를 확인하고, 요청한 위치에 복원됐는지 별도로 구분합니다. `.roughscore`와 `.roughscorepkg` 확장자는 대소문자를 구별하지 않습니다. 처음 저장하거나 기존 프로젝트를 열면 이후 입력은 800ms 후 자동 저장합니다. 마지막 프로젝트를 다시 열어 작업을 이어갑니다. 채보 실행 취소·다시 실행은 최근 100개 편집을 보관하며 두 자리 프렛 입력은 한 번에 되돌립니다. 앱을 종료하면 실행 취소 기록은 사라집니다.
- 프로젝트별 작업 위치·보기 설정은 문서와 분리해 `~/Library/Application Support/RoughScore/WorkspaceSessions-v1`의 작은 원자적 JSON에 저장합니다. cursor, Guitar L/R, 원곡/스템, Stereo/L/R 채널, 구간 시작·확대, 재생 속도, 악보/구간 보기, 줄당 마디 수, 페이지·따라가기, 양쪽 lane·파형·음표 길이·박 스냅 표시, A–B 반복을 복원합니다. 문서 dirty·자동 저장·실행 취소·수동 TAB 시간/ID/nil은 바뀌지 않습니다. 재생은 일시 정지 상태로 열고 선택·입력 중 프렛·드래그·inspector는 초기화합니다.
- 세션은 표준화한 프로젝트 절대 경로의 SHA-256 키와 제목·원곡 asset UUID(legacy v1은 audioPath)로 구분합니다. A/B 프로젝트는 독립적입니다. `다른 이름으로 저장`과 `사본 저장`은 현재 보기를 새 목적지에 복사하며, 사본은 활성 세션·문서 목적지를 바꾸지 않습니다. Finder에서 이름/위치를 바꾼 프로젝트는 새 경로의 기본 보기로 열립니다. 세션은 Mac 로컬 설정이며 패키지나 외부 오디오 안에 넣거나 함께 옮기지 않습니다.
- 세션 v1 JSON은 최대 16KiB입니다. 누락·잘못된 JSON·지원하지 않는 버전·다른 문서의 기록은 안전한 기본값으로 열고, 시간/확대/페이지/반복은 현재 오디오 길이와 활성 asset의 레이아웃에 맞춥니다. 사용할 수 없거나 저장한 UUID와 다른 스템은 원곡으로 돌아갑니다. 보기 변경과 재생 tick은 1초 단위로 모아 저장하고, 프로젝트 전환·저장·종료 시 마지막 위치를 기록합니다. 세션 저장 실패는 하단 상태에 표시하며 이미 저장된 TAB, dirty, 실행 취소를 되돌리지 않습니다. 다른 파일·symlink·손상된 세션은 덮어쓰거나 자동 삭제하지 않습니다.
- 온라인 서비스·외부 모델 다운로드는 없습니다. Apple 분석과 오디오 처리는 기기에서 수행됩니다.

## 실제 곡으로 확인한 결과

DEAR MY WAKER MP3(243.973초, 스테레오 44.1kHz)를 앱에서 열어 검증했습니다. 채널당 24,398개의 파형 값을 준비했고, 원곡·L·R 분석을 따로 실행해 저장했습니다. 원곡 분석 결과는 약 140 BPM, 시작 조성 F minor, 569개 박, 17개 구조 구간입니다. 이는 프레임워크의 검출 결과이며 채보 정답을 뜻하지 않습니다.

악보 파형과 바로 아래 TAB의 같은 가로 위치를 클릭해 1.551초로 일치하는 것을 확인했습니다. 위치 확인용 메모는 삭제했고, 원곡 경로와 분석만 담은 프로젝트는 `build/DEAR-MY-WAKER.roughscore`에 저장했습니다. 원곡 MP3는 수정하거나 복사하지 않습니다.

실제 오디오 통합 테스트는 `ROUGH_SCORE_AUDIO_FIXTURE` 환경 변수로 파일 경로를 받습니다. 지정하지 않으면 해당 테스트는 오디오를 읽지 않습니다. macOS 오디오 디코더 서비스가 제한된 샌드박스에서는 MP3 읽기가 실패할 수 있어 이 검증은 일반 실행 환경에서 수행했습니다.

## 빠른 입력 단축키

| 입력 | 동작 |
| --- | --- |
| 0–9 | 현재 음 또는 커서에 프렛 입력 |
| 1/2 뒤에 숫자 | 0.9초 이내이면 10–24 프렛 입력 |
| ↑ / ↓ | 기타 줄 이동 |
| ← / → | 선택한 음 이동 / 선택 없으면 커서 ±50ms 이동 |
| Shift + ← / → | 시간 ±10ms 이동 |
| Tab / Shift+Tab | 다음 / 이전 메모 |
| Delete | 선택 음 삭제 |
| Esc | 드래그 취소(선택 유지) / 다시 누르면 선택 해제 |
| ⌘Z / Shift+⌘Z | 채보 실행 취소 / 다시 실행 |
| ? / T | 음 미확인 기록(선택 없으면 새 메모) / 잠정 표시 |
| Enter | 지정 간격만큼 다음 입력 위치로 이동(기본 50ms) |
| Space | 재생 / 정지 |
| S / L / R | Stereo / 왼쪽 / 오른쪽 듣기 |
| − / + | 감속 / 속도 복구 |
| [ / ] | 반복 시작 / 끝 지정 |
| \ | 반복 켜기 / 끄기 |
| I | 상세 편집 패널 |

파형 클릭 → ↑ → ? → → → 1,2로 포인터를 다시 쓰지 않고 미확인 메모와 12프렛 메모를 따로 남길 수 있습니다. `?`로 새 미확인 메모를 기록하면 선택을 마치며 커서는 그대로 유지합니다. `Enter` 또는 `다음`은 명시적으로만 위치를 옮기고, `…`에서 이동 간격을 ms 단위로 지정합니다. 음표 길이나 쉼표, 자동 진행을 추정하지 않습니다.

단축키는 악보를 클릭해 입력 초점이 있는 상태에서 사용합니다. 상세 패널의 텍스트 필드에는 일반 텍스트를 입력합니다. 메모 선택 시 상세 패널이 자동으로 열리지 않으므로 악보와 파형의 가로 위치가 유지됩니다.

## 위치 조절

- 악보 또는 구간 편집 화면에서 음 숫자를 잡아 끌어 시간을 옮깁니다. 위아래로 끌면 기타 줄도 바뀝니다. 이동 중에는 파형까지 이어지는 가이드와 초 단위 위치를 표시합니다.
- 기본 드래그는 자유 이동입니다. Shift를 누르는 동안에만 같은 L/R 파트의 가까운 다른 음에 시간 위치가 붙습니다. 범위는 약 10 화면 포인트이며 확대·페이지 맞춤에서도 화면 거리로 계산합니다. Shift를 놓으면 원래 포인터 위치로 돌아가 자유롭게 이동합니다. 위아래 기타 줄 이동도 가능합니다. Option을 누른 채 시작하면 이동 속도가 1/5로 줄어듭니다.
- 드래그 미리보기는 프로젝트를 변경하지 않습니다. 드래그 중에는 숫자·화살표·T·?·Tab·Delete·다시 실행과 상세 필드 변경을 받지 않습니다. 마우스를 놓을 때 한 번 적용하며, 첫 Esc는 선택을 유지한 채 이동을 취소하고 다음 Esc는 선택을 해제합니다. 적용 후 ⌘Z 한 번으로 원위치로 되돌립니다.
- 생성·이동·탐색·초 입력은 같은 시간 경계를 사용합니다. 허용 시간은 `0 ≤ time < duration`이며 마지막 1ms를 잘라내지 않습니다. 1프레임짜리 오디오와 1ms 미만 프로젝트도 유효한 시간으로 저장할 수 있습니다. 숫자가 아닌 값은 적용하지 않고, 초 입력칸을 보기만 한 경우에는 표시 반올림으로 원래 시간이 바뀌지 않습니다.
- 음을 더블 클릭하거나 확대 버튼을 누르면 해당 음 주변 2초를 크게 보여줍니다. 1·2·3초 범위와 확대/축소 버튼으로 더 세밀하게 볼 수 있습니다.
- 상단 초 입력칸에 정확한 시간을 입력하고 Enter로 적용할 수도 있습니다. 다른 줄·페이지로 멀리 옮길 때는 음을 선택하고 Option+클릭으로 목적지를 지정합니다.
- 선택한 음의 위치 편집 중에는 화면이 자동으로 따라가거나 기존 반복 구간이 해제되지 않습니다. 원하는 위치에서 듣기는 Shift+Space 또는 듣기 버튼으로 실행합니다.
- 별도 실제 곡 복사본에서 악보 드래그(1.559초/2번 줄 → 2.382초/4번 줄), 한 번의 실행 취소, 2초 확대 후 드래그, 2.550초 직접 입력, 페이지 맞춤 좌표 변환을 확인했습니다.

### 겹친 음 선택

같은 줄에서 짧은 간격 또는 같은 시간에 있는 음은 프렛 옆에 `×개수`가 표시됩니다. 프렛을 클릭할 때마다 그 그룹의 다음 음을 선택하며, `×개수`를 클릭하면 각 음의 실제 초 단위 시간·L/R·줄·프렛·잠정 표시·길이·메모를 보고 원하는 음을 직접 선택할 수 있습니다. 선택한 프렛을 드래그하거나 숫자를 입력해 그 음만 편집합니다. 더블 클릭하면 선택한 음 주변을 확대합니다.

선과 작은 눈금은 원래 시작 위치를 표시합니다. 겹침 표시와 페이지 맞춤·확대는 저장된 시간·ID·줄·L/R을 바꾸지 않으며, Shift 마그넷도 표시 라벨이 아닌 실제 시작 위치를 사용합니다. 겹치지 않는 음에는 개수 표시가 추가되지 않습니다.

### Shift 마그넷

가까워진 음이 붙을 때 대상 음을 강조하고 가이드에 `붙음`을 표시합니다. 드래그 중 Shift를 누르거나 놓으면 마우스가 멈춰 있어도 상태를 갱신합니다. 마우스를 놓는 순간의 Shift 상태도 다시 확인합니다. 자신, 반대 L/R 파트, 현재 줄/편집 범위 밖의 음은 대상으로 사용하지 않습니다. `새 음 박 스냅`은 신규 음 입력에만 적용하며, 일반 드래그를 제한하지 않습니다.

### 상세 메모 입력과 실행 취소

메모 필드는 일반 AppKit 텍스트 편집기로, 입력 초점이 있는 동안 ⌘Z/⇧⌘Z는 텍스트의 자체 기록과 커서를 유지합니다. 필드를 떠난 뒤 채보 실행 취소 한 번은 그 필드 편집을 되돌리고, 다음 실행 취소는 앞선 채보 작업을 되돌립니다. 101자 입력이나 입력 중 자동 저장이 이전 음 생성 기록을 밀어내지 않습니다. 같은 값·유효하지 않은 값·오래된 선택의 필드 요청은 데이터나 redo 기록을 바꾸지 않습니다.
